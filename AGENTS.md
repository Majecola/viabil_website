## Product Overview

**What VIABIL does:**

VIABIL é um software de planejamento e simulação de negócios imobiliários que apresenta resultados, indicadores e fluxo de caixa para que os clientes possam tomar decisão de forma mais segura e assertiva, em todos os estágios do empreendimento.

VIABIL participates in every stage: from the initial Go/No-Go decisions, land acquisition analysis, development and launch, through planned vs. actual monitoring and replanning. In each stage, it is possible to simulate, analyze, and adjust according to reality.

A key differentiator: VIABIL is a market standard — shared between partners, incorporated investors, and joint ventures. Using the same tool as the market means analyses are credible and discussions focus on premises, not calculation methods.

## Product Modules

### Gestão de Terrenos (Cadastro de Terrenos)
Central module for land acquisition and origination teams (Novos Negócios).
- Centralizes all offered/prospected land information: location, infrastructure, topography, zoning, documents, images.
- 40+ combined search filters (area, VGV potential, profile, zoning, etc.).
- Google Maps geolocation integration.
- Document management: matrícula, estudos de massa, topográficos, pesquisas, fotos.
- Follow-up de tarefas (checklist, deadlines, responsible person, pending control).
- Negotiation history (who, when, at what price, reason for rejection).
- Professional presentation layouts exported to Excel.
- Direct link to start a Viabilidade study from a selected land entry.

### Viabilidade
Main module. Where feasibility studies are created, simulated, and analyzed.
- Supports all segments: incorporação residencial, casas, loteamentos, MCMV, médio e alto padrão, corporativo, galpões logísticos, BTS, shopping centers, mistos.
- Full cash flow projections, indicators, and sensitivity analysis in real time.
- **Stress-cenário:** sensitivity analysis on key variables — sale price, construction cost, financial permuta %, sales velocity, interest rates, rental yield/m², cap-rate.
- **Premissas:** obra/infra curves, commercial assumptions, financing models (SFH, Crédito Associativo, MCMV, securitização), partners/investors structures.
- Parametrizable indicators and acceptance benchmarks by segment and region.
- Templates/modelos for fast replication of common business structures.
- Full history of all scenarios created for each project.
- Reports: Premissas, Fluxos de Caixa (sintético e analítico, nominal, indexado, VP), Previsão de Resultados, Análise de Sensibilidade, Tabelas de Venda, Cronograma de Obra e Vendas — all exported directly to Excel.
- Key indicators: Margem, VPL, TIR, MTIR, Exposição Máxima e Média, Investimento Máximo (Risco), ROI, Yield, Payback — for the project and for each partner/investor separately.

### Acompanhamento
Continuous monitoring module from land acquisition through project close.
- Compares planejado x revisado x realizado across all stages.
- Imports actual data from ERPs, spreadsheets, or TXT files (de→para account plan mapping).
- Divergence analysis and automatic alerts.
- Exclusive wizard for generating tracking scenarios with automatic reprojeção of balances, sales mirror, and work curves.
- Enables replanning and simulation of new actions to return to original targets.
- Dashboard with "health" indicators: margem, obra prevista, venda acumulada, TIR.
- Supports partner/investor monitoring without requiring their ERP access.
- Guarantees the same management view (same indicators, same formats) throughout the entire project cycle.

### Consolidação de Resultados
Portfolio-level view across all projects.
- Consolidated cash flow and indicators for: projects in prospection (landbank), projects in development, and future business models.
- Comparative analysis between scenarios of the same project or different projects.
- Identifies best opportunities from competing options.
- Shows predicted capital inflows/outflows for shareholders over time.
- Supports strategic planning and board-level reporting.

### Workflow de Tarefas
Task and process control throughout the development lifecycle.
- Manages activities from land captação through chaves/recebíveis.
- Defines process stages, checklists, deadlines, and responsible parties.
- Real-time pending task view per user on login.
- Managers can monitor execution and send automated email reminders.
- Full activity history for each land or project.

## Lead Generation

### WhatsApp Business API

The primary lead conversion channel is WhatsApp Business.

Two entry points:

1. Hero section CTA button — primary "Solicitar demonstracao" or "Falar com especialista" action, opens WhatsApp with a pre-filled message in Portuguese.
2. Sticky floating button — fixed to the bottom-right of every page, a circle in the VIABIL primary green (`#0A4B35`), containing the WhatsApp icon. Visible on all pages throughout the full scroll. This will eventually evolve into a virtual assistant/agent entry point.

Implementation:
- Use the `https://wa.me/` deep link format with a pre-filled message.
- Phone number and pre-filled message stored as environment variables.
- The floating button must be accessible: `aria-label`, visible focus state, `prefers-reduced-motion`-safe animation.
- The floating button must not overlap important page content at any breakpoint (1440px, 1024px, 768px, 440px, 360px).

1. Supabase Postgres table — lead with timestamp, name, email, phone, company, message, segment selection, and source page.
2. Email notification to a designated VIABIL employee — triggered server-side via a transactional email provider (Resend or similar). Email address stored as an environment variable.

- **Ligamos para você** — name, email, company (optional), phone (at least one of fixed/mobile required).
- **Solicite uma proposta** — name, email, company, phone, preferred contact method, segment(s) of operation (multiple choice), message (optional), how they heard about VIABIL.
- **Agende uma apresentação** — name, email, company, phone, city/state, segment(s) (at least one required), message (optional), how they heard about VIABIL.
- **Converse sobre parcerias** — name, company, email, phone, message.

## Fullstack Architecture

Use:
- Next.js App Router.
- TypeScript.
- Tailwind CSS.
- shadcn/ui.
- Supabase Postgres for lead storage and admin auth.
- Supabase Row Level Security on the leads table.
- Resend (or similar) for transactional email notifications.
- Vercel for deployment and preview environments.

Suggested structure:

```txt
app/
  (public)/         public marketing pages
  admin/            protected admin panel (VIABIL staff only)
  api/
    contact/        server-side form handler
    auth/           Supabase auth callbacks
components/
  marketing/
  animation/
  admin/
  ui/
lib/
  supabase/
  email/
  validation/
supabase/
  migrations/
public/
  assets/
```

Security:
- RLS on all Supabase tables that store lead or user data.
- Server-side validation for all form mutations.
- Admin routes protected on the server via middleware checking session and admin role.
- Email credentials and Supabase service role key in environment variables only.
- Admin panel not linked or indexed publicly.
- Separate preview and production environment configuration.
