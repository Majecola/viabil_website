# VIABIL Context Reference

This document summarizes the business, product, marketing, brand, and technical context for the VIABIL website. It is intended to be the readable project reference for designers, developers, copywriters, and AI coding agents working on the site.

## 1. Project Overview

The VIABIL website is a public marketing and lead generation site for the VIABIL platform.

Its primary goals are:

- Raise awareness of VIABIL as a Brazilian reference in real estate financial feasibility.
- Communicate strategic value to executives and investment decision-makers.
- Explain the platform beyond initial feasibility analysis.
- Capture leads through WhatsApp, demo CTAs, newsletter forms, and contact forms.
- Support future admin workflows for VIABIL staff to manage lead submissions.

The site is not the VIABIL software product itself. It is a public commercial website.

The public site must not include:

- Public user registration.
- Customer login or profile pages.
- Training booking flows.
- Stripe or payment processing.
- Public product dashboards.

The only protected area planned for the website is the admin lead management panel for VIABIL staff.

## 6. Product Overview

VIABIL is a software platform for planning, simulating, analyzing, monitoring, and replanning real estate business opportunities.

The platform presents:

- Results.
- Indicators.
- Cash flow projections.
- Scenario comparisons.
- Sensitivity analyses.
- Reports.
- Portfolio views.
- Planned versus actual comparisons.

The goal is to support safer and more assertive decision-making across all stages of the real estate development cycle.

Typical cycle:

1. Business opportunity or land is identified.
2. Land and opportunity data is organized.
3. Initial Go/No-Go decisions are evaluated.
4. Feasibility studies are created.
5. Scenarios and stress cases are simulated.
6. Investment decisions are made.
7. Approved projects are monitored.
8. Planned, revised, and actual results are compared.
9. New routes are simulated when reality changes.
10. Portfolio results are consolidated for strategic decisions.

Important differentiator:

VIABIL is a market standard. When partners, developers, investors, and joint ventures use the same platform and methodology, discussions focus on premises and business decisions instead of formula credibility.

## 15. Admin Lead Panel

The `/admin` route is for VIABIL staff only.

Authentication:

- Supabase Auth magic link.
- Email OTP.
- No public passwords.

Admin V1 features:

- View lead submissions.
- Filter by date, status, and segment.
- Mark leads as contacted.
- Mark leads as closed.

Security:

- Admin panel is not linked from public pages.
- Admin panel should be `noindex`.
- RLS protects lead data.
- Only admin-role authenticated users can read lead submissions.
- Public form submissions use a server-side API route with a service role key that is never exposed to the browser.

Suggested structure:

```txt
app/
  (public)/
  admin/
  api/
    contact/
    auth/
components/
  marketing/
  animation/
  admin/
  ui/
lib/
  supabase/
  email/
  validation/
supabase/
  migrations/
public/
  assets/
```

Technical rules:

- Use Server Components by default.
- Use Client Components only for interactivity and animation.
- Preserve accessibility attributes.
- Preserve focus-visible states.
- Preserve reduced-motion handling.
- Validate user input at server boundaries.
- Do not expose private credentials.
- Do not add analytics snippets without confirming provider and consent requirements.
